# LADY10 Handmade & Tailoring — CEP Website

A simple responsive digital catalogue website created for the Community Engagement Project:
"IT Support for Self-Help Groups and Micro-Entrepreneurs."

## Included
- Home/hero section
- Product/work gallery using the supplied business photos
- Services
- Exact tailoring rate card from the supplied rate card
- Digital catalogue section
- Business/visiting card
- Custom-order demo enquiry form
- Contact section
- Responsive mobile navigation
- Print-friendly rate card

## Run
Open `index.html` in a browser.

## To customize later
- Replace the placeholder phone number and Instagram handle in `index.html`.
- Connect the enquiry form to WhatsApp, email, Google Forms, PHP/MySQL, or another backend.
- Add real business social links when available.
